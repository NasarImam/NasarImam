**RideX** — Distributed ride-sharing platform · in active development
A from-scratch distributed platform for real-time ride matching, driver–rider coordination, trip management, and concurrent request processing. Built to understand how large-scale systems like Uber and Lyft handle distributed services, location-based matching, concurrency, fault tolerance, and real-time communication rather than simply consuming their APIs.

End-to-end churn analysis on a 7,043-customer dataset: SQL-based cleaning and segmentation, two interactive Power BI dashboards, and retention recommendations tied to a 26.5% churn finding.
